# Start Here — AutoTrader AI

1. Make a NEW GitHub repo, e.g. `autotrader-ai-paper`. Do not reuse your existing AutoMind production repo.
2. Open the new repo in Claude Code (local terminal or cloud workspace).
3. Add these 3 markdown documents to the repository root (`PROJECT_BLUEPRINT.md`, `CLAUDE_MASTER_PROMPT.md`, `README_START_HERE.md`).
4. Paste the contents of `CLAUDE_MASTER_PROMPT.md` into Claude Code, or ask: `Read CLAUDE_MASTER_PROMPT.md and execute Phase 0, including code and tests.`
5. Approve only read-only/public API calls and local dev filesystem/database operations in the first phase. Do not provide wallet keys or USDC.
6. Review the data coverage report and safety test results before proceeding through later phases.
7. Any future live-trading capability requires a separately scoped, explicitly authorized project; this repository must remain paper-only.
